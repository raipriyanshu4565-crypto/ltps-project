CAMPUSFIND – Smart Campus Lost & Found Matcher

📌 About the Project

CampusFind is a C-based Smart Campus Lost & Found Management System designed to help students report, search, and recover lost belongings within a college campus. It provides an easy-to-use, menu-driven interface with automatic data storage and smart matching suggestions.

✨ Features

- Add Reports: Register lost or found items.
- View Reports: Display all registered reports.
- Search Items: Search by item name, category, color, or location.
- Smart Matching: Suggest possible matches between lost and found items.
- Status Management: Update reports as OPEN, MATCHED, or RETURNED.
- Statistics: View total lost, found, matched, and returned reports.
- File Handling: Automatically save records in a text file.
- Unique Report ID: Generate a unique ID for every report.

⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code or any C compiler.
3. Compile the source code:

gcc campusfind.c -o campusfind

4. Run the program:

Windows:

campusfind.exe

Linux / macOS:

./campusfind

💾 Data Storage

All reports are stored in "campusfind_data.txt" using file handling. Saved records are automatically loaded when the program starts.

🎯 Project Objective

The main objective of CampusFind is to make lost-and-found management easier, faster, and more organized within educational institutions.
